
# CREA BOX

## Descripción
CREA BOX es una plataforma virtual de venta de kits creativos. El sistema permite gestionar productos y categorías mediante una aplicación web.

## Tecnologías utilizadas
- Java 21
- Spring Boot 3.5.7
- Maven
- MySQL
- HTML
- CSS
- JavaScript

## Requisitos previos
Para ejecutar CREA BOX en un computador se necesita:

1. Java JDK 21.
2. Apache Maven instalado y configurado en el PATH.
3. MySQL Server.
4. Una base de datos llamada `crea_box` con las tablas requeridas por el sistema.

## Instalación y ejecución

1. Descargar el proyecto desde GitHub.
2. Descomprimir la carpeta del proyecto.
3. Verificar que Java, Maven y MySQL estén instalados.
4. Configurar la base de datos MySQL.
5. Abrir la carpeta principal `C_CREA-BOX`.
6. Ejecutar el archivo `Iniciar_CREA_box_portable.bat`.
7. Ingresar la contraseña de MySQL cuando sea solicitada.
8. Esperar a que inicie el servidor.
9. Abrir el navegador en:

   http://localhost:8080/

## Base de datos
La conexión utiliza MySQL y la base de datos `crea_box`.

El archivo `database/crea_box.sql` contiene una consulta SQL de ejemplo. La estructura completa de la base de datos debe estar configurada antes de ejecutar el sistema.

## Puerto de ejecución
La aplicación utiliza el puerto 8080.
